# Documentation site

Edit the pages and demos in `src_docs/md/`. Keep the fly-january theme's `extra.fly.chrome` set to `none` in `src_docs/mkdocs.yml`. Run `./build.sh docs` to rebuild `docs/` in strict mode. The build requires fly-january 0.4.0 or later (remote theme assets) in `src_docs/build.sh`.
