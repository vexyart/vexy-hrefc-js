3. Thumbnails

A picture on the card, when one can be found. Off by default — pictures cost a round trip.

Turn it on

Flip thumbnail to true. The text shows first; the image slides in once it loads, so a slow picture never holds up the card.

<script src="https://cdn.jsdelivr.net/npm/vexy-hrefc/dist/hrefc.global.min.js"></script>

<script>
  Hrefc({
    content: { thumbnail: true },
  });
</script>

Where the picture comes from

vexy-hrefc tries a few sources in order and stops at the first that works:

1. the page's own og:image → 2. an mShots screenshot (keyless) → 3. Microlink → 4. a click-protected iframe of the page itself → 5. nothing, and the card stays text-only. No broken-image icon, no fuss.

See it

These links all ship a good og:image, so the card gets the real article picture. The card is taller than a text-only one — that's expected.
