1. The one-liner

Add a class to a link, call one function. That's the whole setup.

The code

Load the script, mark the links you want previewed with class="hrefc", and start it.

<script src="https://cdn.jsdelivr.net/npm/vexy-hrefc/dist/hrefc.global.min.js"></script>

<a class="hrefc" href="https://en.wikipedia.org/wiki/Hyperlink">hyperlink</a>

<script>
  Hrefc(); // uses sensible defaults
</script>

What it does

Hover a link below. After a beat, a card fades in with the target's title and description. No click, no new tab. Leave, and it's gone.
